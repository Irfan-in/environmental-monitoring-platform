📱 3. Running in Android Studio + Android Emulator

  1. Open Project: Open Android Studio → Click Open → Select environmental_monitoring_platform/frontend.
  2. Boot Virtual Device: Open Device Manager → Click Play (▶) on your virtual Android device (Pixel 7 / API 34).
  3. Launch App: Select the running emulator from the device menu → Click the green Run (▶) button (or Shift + F10).
⚠️ Critical Emulator Rule (10.0.2.2 vs 127.0.0.1):
Inside the Android Emulator, your computer's localhost is 10.0.2.2.
In the app: Tap Alerts tab → Tap the settings icon (⚙️) → Set Server URL to http://10.0.2.2:8080 → Tap Save & Reconnect.

🔬 4. ESP32 Hardware Emulation (Zero Hardware Needed)

Method A: Terminal ESP32 Simulator (Instant 1-Click)

Run python simulate_esp32.py in a separate terminal. It generates a live ASCII OLED box in the console and broadcasts real sensor telemetry every 3 seconds to the local backend.

Method B: Wokwi Online Graphical Simulator (Interactive Circuit)

  1. Navigate to wokwi.com/projects/new/esp32.
  2. Paste the code from PHONE_DEMO_PACKAGE/esp32_sensor_node/esp32_sensor_node.ino into the sketch.ino tab.
  3. Click the diagram.json tab and paste the pre-wired configuration from esp32/wokwi_diagram.json:
{
  "version": 1,
  "author": "Mohammed Irfan KS",
  "editor": "wokwi",
  "parts": [
    { "type": "wokwi-esp32-devkit-v1", "id": "esp", "top": 0, "left": 0 },
    { "type": "wokwi-dht22", "id": "dht", "top": -120, "left": -80, "attrs": { "temperature": "25.5", "humidity": "55" } },
    { "type": "wokwi-ssd1306", "id": "oled", "top": -120, "left": 80, "attrs": { "i2cAddress": "0x3c" } }
  ],
  "connections": [
    [ "dht:VCC", "esp:3V3", "red", [ "v0" ] ],
    [ "dht:GND", "esp:GND.1", "black", [ "v0" ] ],
    [ "dht:SDA", "esp:D4", "green", [ "v0" ] ],
    [ "oled:VCC", "esp:3V3", "red", [ "v0" ] ],
    [ "oled:GND", "esp:GND.2", "black", [ "v0" ] ],
    [ "oled:SDA", "esp:D21", "blue", [ "v0" ] ],
    [ "oled:SCL", "esp:D22", "yellow", [ "v0" ] ]
  ]
}

4. Hit Start Simulation (▶). The virtual OLED lights up with your name, and dragging the DHT22 temperature slider immediately triggers threshold alerts!

🏛️ 6. System Architecture & Hardware Pinout

Component Physical / Logical Pin Role / Protocol
DHT22 Data GPIO 4 Single-bus digital temperature & humidity reading
SSD1306 OLED SDA GPIO 21 I2C Data line for 128x64 local display
SSD1306 OLED SCL GPIO 22 I2C Clock line (Address 0x3C)
Gateway Discovery WiFi.gatewayIP() Auto-targets phone IP on port 8080 (zero hardcoding)
Backend Engine FastAPI + SQLite WAL Universal runner (FastAPI or pure standard-library)
Cloud Hosting render.yaml Free 24/7 HTTPS deployment on Render.com
